# Qingmo Docs

Qingmo Docs is a collaborative document editor built with NestJS, PostgreSQL, ProseMirror, Tiptap, and Yjs.

## Workspace

- `apps/backend/server` - NestJS backend
- `apps/frontend/web` - Vite + React web app
- `packages/core` - shared editor core
- `packages/react` - React bindings

## Scripts

- `pnpm lint`
- `pnpm lint:fix`
- `pnpm fmt`
- `pnpm fmt:check`
