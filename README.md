# Qingmo Docs

Qingmo Docs is a collaborative document editor built with Go, Gin, PostgreSQL,
ProseMirror, Tiptap, and Yjs.

## Workspace

- `apps/backend/server` - Go + Gin backend
- `apps/frontend/web` - Vite + React web app
- `packages/core` - shared editor core
- `packages/react` - React integration and public editor entry
- `packages/editor-ui` - editor components, node views, and toolbar composition
- `packages/shadcn` - shared UI components, utilities, and theme
- `playground` - Vite sandbox for editor UI and shared primitives

## Scripts

- `cp apps/backend/server/.env.example apps/backend/server/.env` - create the
  local backend environment file
- `pnpm db:start` - start PostgreSQL for local development
- `pnpm dev` - start all workspace development processes, including the Go
  server
- `pnpm --filter @qingmo/server dev` - start only the Go server
- `pnpm dev:playground` - start the playground and watch its editor packages
- `pnpm --filter @qingmo/playground dev` - build the editor dependencies and
  start the playground at `http://localhost:5174`
- `pnpm exec turbo run build --filter=@qingmo/playground` - build the playground
  and its workspace dependencies
- `make -C apps/backend/server dev` - start only the Go server without pnpm
- `pnpm build`
- `pnpm check-types`
- `pnpm lint`
- `pnpm lint:fix`
- `pnpm fmt`
- `pnpm fmt:check`
- `pnpm shadcn:add dialog` - add shadcn components using the web app's
  configuration; shared UI components are generated in `packages/shadcn`
- `pnpm --filter @qingmo/playground shadcn:add dialog` - use the playground's
  configuration; shared UI components still go to `packages/shadcn`

## Editor Packages

`@qingmo/core` owns the editor schema and behavior. `@qingmo/react` integrates
that core with components from `@qingmo/editor-ui` and exposes the public editor
entry. Editor UI owns concrete view components and depends on shadcn; it does
not depend on the Qingmo React package. Web and playground consume the React
entry for editor interfaces and shadcn for their other page UI.

The React entry currently exports `EditorFrame`, a reusable toolbar and content
layout implemented in editor-ui. Concrete node views and editor initialization
APIs will be added to their respective packages.

See [the React integration package](packages/react/README.md) and
[the editor UI package](packages/editor-ui/README.md) for package boundaries and
usage. Core and React keep their existing dist builds. Editor UI is a private
source package compiled by each consuming application.

## Shared UI

The web app, playground, and editor UI depend on the private source package
`@qingmo/shadcn`. It owns reusable UI components, `cn`, `showToast`, and the
shared theme. App-specific components such as the login page's
`AnimatedCharacters` remain in the web app. Business blocks generated by the
shadcn CLI stay in the app where the command is run.

See [the shared UI package](packages/shadcn/README.md) for imports, styles, and
component generation. The package is consumed directly from source within this
workspace and has no separate build or npm publishing workflow. Editor hosts
import `@qingmo/react/styles.css`, which includes the shared theme and scans
editor UI source, then register their own source with Tailwind's `@source`.
